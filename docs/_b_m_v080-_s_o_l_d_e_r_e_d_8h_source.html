18// The BMV080 Bosch API requires a larger than usual stack size
19// In particular, bmv080_serve_interrupt is the culprit.
20// If we are an ESP32 architecture, then we need to increase the loop stack size
21// to 60KB. This is because the ESP32 has a 32KB stack size by default.
